Fitness_Tracking_System

Fitness Tracking System developed by Reysha Sorsano, Nielyn Joy Aquilisca, and Leonel De los Reyes

Programming Tools Used:
Frontend: Angular + Tailwind CSS
Backend: Node.js + Express.js + TypeScript
Database: MongoDB Atlas

This Fitness Tracking System has two users:
User and Admin

- User:

* Can register and create their own account

* Can login securely using JWT Authentication

* Can track daily workouts and fitness activities

* Can add, edit, and delete workout records

* Can set fitness goals and monitor progress

* Can upload progress images and profile pictures

* Can view dashboard analytics such as calories burned, workout duration, and activity progress

* Can manage personal profile information

* Can search and filter workout history

* Can access responsive dashboard UI using Angular and Tailwind CSS

- Admin:

* Can manage registered users

* Can view all workout records

* Can manage uploaded files and user activity

* Can access protected admin dashboard

* Can authorize and manage user roles

* Can monitor overall system activity

Additional Features:

* JWT Authentication and Authorization

* Protected Routes using Angular Route Guards

* RESTful API Architecture

* File Upload using Multer

* MongoDB Database Integration

* Responsive User Interface

* Error Handling and Middleware

* CRUD Operations for Workouts and Goals

* Search, Filtering, and Pagination

* API Integration using Angular HTTP Client and RxJS

Other Requirements:

* Node.js
* Angular CLI
* MongoDB Atlas Account
* GitHub Repository
* Internet Connection for Database Hosting

For Database:
MongoDB Atlas cloud database is used for storing user accounts, workout data, goals, uploads, and system information.
